# Sound-Kit Solleva (Entwurf v0.1)

Quelle: **Mixkit** (mixkit.co), Mixkit Sound Effects Free License: kostenlos, auch kommerziell, ohne Namensnennung. Nicht als einzelne Sound-Datei weiterverkaufen/weitergeben.

Auswahl abgeleitet aus der Sound-Analyse der Referenzen (`docs/referenzen/sound-analyse.md`).
`sounds.json`: pro Sound Kategorie, Dauer, **Einsatz** (erster hörbarer Moment) und **Hit** (lautester Moment) in Sekunden. Beim Anlegen im Reel den Hit auf das Bildereignis legen (Swish: Hit 1–3 Frames vor der Bewegung, Schlag/Klick exakt auf der Landung).

| Kategorie | Wofür |
|---|---|
| swish | kurze, fallende Swishes: Einflug, Karten, Text |
| whoosh | rauschend, länger: Lupe, Kamerafahrt, Szenenwechsel |
| papier | Karten/Papier schieben, Collage |
| klick | Cursor, Einrasten, Häkchen |
| schlag | Landung, Enthüllung, CTA (dumpf/tief) |
| glitzer | Enthüllung, «Wow»-Moment |
| downlifter | Stakkato, Bruch, Rückspulen |
| riser | Spannung vor grossem Moment |
| pop | Text/Elemente erscheinen |
| glitch | dunkle Stimmung, Störung |
| tippen / schreiben | Tippen, Handschrift, Kringel |

Status: **wird vom Nutzer angehört**; Favoriten und Ergänzungen folgen.
